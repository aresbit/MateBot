Rank: [Jacobsen - FOCs 1989]

① use lookup table for bitstrings of length  $ \frac{1}{2} $ lg n

 $ \Rightarrow O(\sqrt{n}\lg n\lg lg n) $ bits of space

② split into  $ (lg^{2} n) $-bit chunks:

 $ \overbrace{\lg^{2}n}^{} \quad \overbrace{\uparrow_{\text{store cumulative rank: } \lg n \text{ bits}}}_{\Rightarrow O(\frac{n}{\lg^{2}n} \lg n)} = O(\frac{n}{\lg n}) \text{ bits} $

(couldn't afford lg n - bit chunks)

③ split each chunk into  $ \left(\frac{1}{2}lg n\right) $-bit subchunks:

 $  \frac{1}{2} \ln n  $ store cumulative rank within chunk: lgln bits

 $ \Rightarrow O(\frac{n}{lgn} \lg \lg n) = O(n) $ bits

④ rank = rank of chunk

+ relative rank of subchunk within chunk

+ relative rank of element within subchunk (via lookup table)

⇒ O(1) time, O(n  $ \frac{\log n}{\log n} $) bits

- O(n/lgk n) bits possible for any k=0(1) [Patrascu-Focs 2008]

- O( $ \frac{\lg n}{\lg \lg n} $) insert/delete/rank/select [He & Munro-SPIRE 2010]
